# Инструкция пассажира LadyGo

## Создание поездки
1. Войдите или создайте аккаунт.
2. Укажите точку подачи и назначения, проверьте маршрут на карте.
3. Выберите доступный тариф. Предварительная стоимость в текущей версии помечается как оценка по геодезической дистанции, а не гарантированная дорожная цена.
4. Выберите предпочтительный способ расчёта с водителем: наличные или перевод водителю. Онлайн-списание в приложении не подключено.
5. Нажмите «Заказать поездку». Заявка создаётся через серверный подписанный quote и idempotency RPC.
6. После назначения водитель и статус поездки отображаются в приложении; Realtime обновляет изменения при доступном соединении.

## Во время поездки
- Разрешите геолокацию, чтобы водительская позиция отображалась пассажиру. Водителю требуется разрешение на фоновую геолокацию для непрерывного GPS.
- Контакт/звонок доступен только участникам назначенной активной поездки и пока действует контактный lease.
- Используйте чат поездки для связи внутри приложения, если он доступен в текущей сборке.
- Отменяйте поездку через экран заказа; доступность отмены зависит от текущего статуса.

## После поездки
История хранит завершённые поездки; рейтинг/отзыв доступен в соответствующем экране, если этот UI включён в сборке.

## Ограничения
Push зависит от настройки Expo/Supabase и разрешений Android. При отключённых уведомлениях откройте приложение, чтобы получить актуальное состояние из Supabase. Доступность реальной диспетчеризации зависит от применения миграций и deployment Edge Function/scheduler в Supabase; наличие кода в Git само по себе не означает, что backend уже развёрнут.
