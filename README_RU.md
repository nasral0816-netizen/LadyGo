# LadyGo — стартовый проект Android

Это **исходный MVP**, а не готовая служба такси. В проекте есть регистрация по email, профиль пассажира/водителя, создание заявок, список поездок, подтверждение цены водителем и статусы. Адреса пока вводятся вручную; нет карт, GPS, push-уведомлений, оплаты, проверки телефона и полноценной панели диспетчера.

## 1. Что понадобится
- Компьютер Windows / macOS / Linux.
- Node.js LTS (18.18+; предпочтительно актуальная LTS).
- Аккаунт Supabase: https://supabase.com
- Аккаунт Expo: https://expo.dev
- Для команд — PowerShell (Windows) или Terminal (macOS/Linux).

## 2. Создать backend в Supabase
1. Создай новый проект Supabase.
2. Открой **SQL Editor → New query**.
3. Скопируй весь файл `supabase/schema.sql`, нажми Run.
4. Открой **Project Settings → API** и скопируй Project URL и anon/public key.
5. В корне проекта скопируй `.env.example` в `.env`.
6. Заполни `.env`:

```env
EXPO_PUBLIC_SUPABASE_URL=https://ТВОЙ-ПРОЕКТ.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=ТВОЙ_PUBLIC_ANON_KEY
```

Не вставляй `service_role` key в приложение и никому его не публикуй.

## 3. Установить зависимости и запустить
В терминале перейди в папку проекта:

```bash
npm install
npx expo start
```

Установи Expo Go на Android и отсканируй QR-код. Для проверки на телефоне и компьютере они обычно должны быть в одной Wi-Fi сети.

## 4. Назначить водителя
1. Зарегистрируй отдельный аккаунт водителя через приложение.
2. В Supabase открой **Table Editor → profiles**.
3. Найди строку с email водителя.
4. Измени `role` с `passenger` на `driver`.
5. Перезапусти приложение / выйди и войди в аккаунт водителя.

Не делай роль водителя доступной через публичную регистрацию. Назначай её только вручную как владелец backend.

## 5. Собрать APK через Expo EAS
В терминале из папки проекта:

```bash
npm install
npx eas-cli@latest login
npx eas-cli@latest build:configure
```

Если `build:configure` изменит `app.json`, сохрани сгенерированный `projectId` в `extra.eas.projectId`.

Затем собери тестовый APK:

```bash
npx eas-cli@latest build --platform android --profile preview
```

После завершения EAS покажет ссылку на APK. Открой её на Android и установи файл. Для публикации в Google Play обычно нужен AAB:

```bash
npx eas-cli@latest build --platform android --profile production
```

Для публикации в Google Play учётную запись разработчика должен оформлять совершеннолетний владелец службы на свои настоящие данные. Перед публикацией проверь актуальные правила Google Play.

## 6. Что обязательно доделать перед реальными заказами
- Исправить демонстрационный номер телефона в `App.js`.
- Подключить проверку номера телефона, подтверждение личности водителя и безопасную обработку персональных данных.
- Добавить карты, геокодирование, проверку адресов, GPS и push-уведомления.
- Добавить серверную проверку всех переходов статусов и защиту от гонок при принятии одной заявки несколькими водителями.
- Добавить журнал действий, поддержку, обработку жалоб, резервное копирование и мониторинг.
- Проверить RLS-политики независимым специалистом и протестировать сценарии двух разных аккаунтов.
- Проверить лицензирование перевозок, страхование, требования к детским перевозкам и правила работы в регионах СК и КЧР с квалифицированным взрослым специалистом.

**Детские поездки:** в этом MVP нет проверки личности родителя, подтверждённого согласия, безопасной передачи ребёнка или специальных процедур. Поэтому не принимай через него заказы на самостоятельную перевозку несовершеннолетних. Даже поездки с сопровождающим взрослым нельзя запускать, пока не проверены законность, страховка и безопасность.

## Структура
- `App.js` — экраны и логика приложения.
- `src/supabase.js` — подключение backend.
- `supabase/schema.sql` — таблицы и базовые RLS-политики.
- `eas.json` — профили сборки APK/AAB.
- `.env.example` — пример переменных окружения.

## Обновление 1.1 — что добавлено

- Сессия пользователя сохраняется на устройстве через AsyncStorage.
- Новые заявки и изменения заказов обновляются в приложении через Supabase Realtime (если таблица включена в публикацию).
- При регистрации пассажир указывает телефон; он сохраняется в профиле и копируется в заявку.
- Водитель видит номер пассажира в карточке заявки и может позвонить ему.
- Пассажир может отменить собственную заявку, пока водитель её не принял. Отмена выполняется серверной функцией `cancel_my_order`.
- SQL дополнен проверкой допустимых переходов статусов.

### Важно про безопасность и запуск

Телефон в этой версии не подтверждается SMS. Не используй приложение как действующую службу, пока не настроены подтверждение контактов, защита аккаунта водителя, юридические требования, резервная связь и проверка реальных сценариев. Не принимай самостоятельные детские поездки: этот режим не реализован и не должен включаться без подтверждённого согласия законного представителя, проверки личности и безопасной процедуры передачи ребёнка.

### Назначить аккаунт водителем

После регистрации аккаунта водителя найди его UUID в Supabase → Authentication → Users. Выполни в SQL Editor (замени UUID на настоящий):

```sql
update public.profiles
set role = 'driver'
where id = 'ВСТАВЬ-UUID-АККАУНТА';
```

Не добавляй этот SQL в приложение и никогда не помещай `service_role` ключ в `.env` приложения. В клиенте используется только публичный anon/publishable key.

### Сборка после обновления

В корне проекта:

```bash
npm install
npx expo install @react-native-async-storage/async-storage
npx eas-cli@latest login
npx eas-cli@latest build:configure
npx eas-cli@latest build --platform android --profile preview
```

Команда сборки создаёт APK в облаке Expo EAS и выдаёт ссылку, когда сборка завершится. Для публикации в Google Play нужен отдельный production AAB и проверка всех требований Google Play.


## Версия 1.2 — GPS и карта подачи

Добавлены получение координат устройства при явном нажатии пассажира, обратное преобразование координат в адрес (если доступно), карта с маркером места подачи и сохранение координат в заказе. Водитель видит мини-карту точки подачи в карточке заявки. Ввод адреса вручную по-прежнему доступен.

### Обновление базы
Выполни новый блок в конце `supabase/schema.sql` в SQL Editor Supabase. Повторный запуск безопасен.

### Установка зависимостей и сборка
После распаковки/обновления проекта выполни:
```bash
npm install
npx expo install expo-location
npx eas-cli@latest build --platform android --profile preview
```

Для полноценной карты на Android в production-сборке может потребоваться Google Maps API key и его настройка в `app.json`/EAS secrets согласно документации react-native-maps. Карта и GPS требуют теста на физическом устройстве. Геолокация запрашивается только после нажатия кнопки, не в фоне.

**Ограничение:** в этой версии координаты сохраняются только для места подачи. Маршруты, расчёт расстояния/цены, отслеживание водителя в реальном времени, геокодирование произвольных адресов и push-уведомления не реализованы. Не используйте приложение для реальных поездок до проверки безопасности и всех правовых требований.
