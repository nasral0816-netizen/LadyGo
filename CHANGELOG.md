# LadyGo — журнал изменений

## 6.9.2

- Обновлена визуальная система: тёмно-зелёный #176344, золотой #C79A38, песочный #F6F0E4.
- В выборе поездки доступны три услуги: Женский, Детский и Доставка. Внутренние tariff ID сохранены для совместимости с серверным расчётом.
- Карта получила анимированное изменение высоты и рабочий жест на ручке нижней панели.
- Нижняя панель размещается поверх карты с отдельным elevation/zIndex.
- Добавлена эмблема LadyGo без подписи «Такси в Кисловодске»; CI генерирует обычную и адаптивную иконки Android.
- Обновлены Android theme colors и splash screen.

### Ограничения проверки

Сборка APK и проверка на реальном Android должны быть подтверждены GitHub Actions и устройством. Этот changelog сам по себе не означает, что end-to-end поездка была проверена.
